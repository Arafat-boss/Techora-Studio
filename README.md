# Techora Studio — Next-Gen Hardware, Digital Products & Brand Systems

A precision design and engineering studio website built with **Next.js 16 (App Router)**, **React 19**, **TailwindCSS 4**, and **Framer Motion**.

![Techora Studio Preview](public/images/CKjpQCXbgdY4rJr7UEGzaixoAe8.webp)

---

## ⚡ Features & Capabilities

- **✨ Ultra-Premium Dark Aesthetic**: Pure obsidian black canvas (`#000000`) paired with electric neon lime accents (`#a2e435`), corner crosshair marks, and glassmorphic blur panels.
- **🪄 Spring Physics & Micro-Interactions**:
  - **3D Perspective Mouse Physics (`HoverCardMove`)**: Dynamic cards tilt and scale smoothly in response to cursor position.
  - **Contextual Cursor Badge**: Floating follower badge dynamically updates text context (*"Preview gallery"*, *"Explore Service"*, *"Read Article"*).
  - **Animated Fullscreen Drawer**: Morphing hamburger button and staggered navigation links.
  - **Infinite Marquee Ticker**: Smooth loop of partner & client technology brands.
  - **Scroll-Triggered Typography**: Illuminated word-by-word reveal for studio philosophy.
  - **Animated Accordion FAQ**: Smooth expand/collapse with rotating plus/cross indicators.
  - **Sticky Typography Footer**: Massive brand banner with real-time local studio clock.
- **📁 Multi-Page Architecture**:
  - **Home (`/`)**: Hero showcase, services overview, 4-stage interactive process timeline, team grid, testimonials, and FAQs.
  - **Gallery Archive (`/gallery`)**: Filterable category tabs (Hardware, Audio, Wearables, Gaming) with full-screen preview lightbox modals.
  - **About Studio (`/about`)**: Studio mission, interactive statistics counters (10X, 150+, 99.4%), principles, and leadership.
  - **Articles / Journal (`/article` & `/article/[slug]`)**: Category filtering, reading time calculation, author metadata, and markdown article reader.
  - **Contact & Inquiry (`/contact`)**: Discovery form with service selectors, budget range chips, and instant submission states.
  - **Legal Documentation (`/privacy-policy` & `/terms`)**: Formatted privacy policy and terms of service.
  - **Thank You & 404 (`/thank-you` & `/_not-found`)**: Confirmation and error fallback pages.

## 🛠 Tech Stack

- **Framework**: [Next.js 16 (Turbopack)](https://nextjs.org/)
- **UI Library**: [React 19](https://react.dev/)
- **Styling**: [TailwindCSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### 1. Prerequisites
- Node.js 18+ installed

### 2. Installation
```bash
npm install
```

### 3. Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the studio website.

### 4. Production Build
```bash
npm run build
npm run start
```
